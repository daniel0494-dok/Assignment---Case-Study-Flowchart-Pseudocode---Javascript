Mini Project Flowchart, Pseudocode, & Javascript

4 Pillars

1. DECOMPOSITION
   - input : product price, quantity product, status member
   - validation : product price and product quantity must be positive number
   - subTotal : product price \* quantity product
   - discount : 10%
   - output : total payment or "input not valid"
2. PATTERN
   All transaction use same subtotal method.
3. ABSTRACTION
   Use price, quantity, member.
4. ALGORITHMIC
   input -> validation -> subtotal -> discount -> shipping cost -> output
