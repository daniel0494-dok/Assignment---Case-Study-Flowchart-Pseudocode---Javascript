Deskripsi case study : membuat sistem checkout

program menerima tiga input: harga, jumlah, dan status member. Prorgam kemudian menghitung subTotal, dskon, ongkos kirim, serto total pembayaran dengan aturan seperti dibawah

1. harga produk harus berupa angka posifit dan jumlah produk harus berup abilangan bulat positif. Jika tidak valid, program menampilkan pesan input tidak valid dan tidak melanjutkan perhitungan.
2. Subtotal = harga produk \* jumlah produk.
3. Member mendapatkan diskon 10% dari subtotal. Non-member tidak mendapatkan diskon.
4. Setelah diskon, ongkos kirim gratis apabila total setelah diskon minimal Rp250.000. Jika kurang dari Rp250.000, ongkos kirim Rp15.000.
5. Total pembayaran = total setelah diskon + ongkos kirim.
